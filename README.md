# Portfolio — Nikita Slobodeniuc

Portfolio pessoal bilingue (PT/EN) feito com Next.js.

Sou estudante de Desenvolvimento de Software

## O que tem

- Páginas em português e inglês
- Dark / light mode
- Animações com Framer Motion
- Contacto direto através do Gmail
- Botão para copiar o endereço de email

## Stack

- Next.js (App Router) + React + TypeScript
- Tailwind CSS
- Framer Motion + Lenis
- Gmail compose + Clipboard API

## Estrutura

```
src/
  app/           # rotas e server actions
  components/    # UI e secções do portfolio
  content/       # textos PT/EN
  lib/           # helpers (i18n)
public/          # CVs e foto de perfil
```

## Notas

Este projeto foi feito como prática de estudo. As animações e a experiência bilingue foram onde foquei mais tempo. Feedback é bem-vindo.
