> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the backend contact form with direct email actions and align the portfolio, documentation, and bilingual CV PDFs with the deployed implementation.

**Architecture:** A focused client component will render a standard `mailto:` link and use the browser Clipboard API for the copy action. The existing server action, form component, and direct Resend/Zod dependencies will be removed. Public copy and both one-page PDFs will be updated without changing unrelated professional information.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS 4, PyMuPDF, npm

- Keep `.claude/` and `.cursor/` local and untouched.
- Do not add code comments.
- Keep the existing contact section visual style and responsive behavior.
- Use `nikitayxp@gmail.com` for both contact actions.
- Support Portuguese and English labels and copy feedback.
- Do not add a backend, API, external contact service, environment variable, or new runtime dependency.
- Keep each CV readable, selectable, and limited to one page.
- Preserve unrelated CV experience, education, skills, project details, and contact information.
- Do not merge to `main` before user approval.
